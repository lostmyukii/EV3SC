# VSLE Scratch-EV3 完整安装向导

本向导面向老师、助教和内部测试人员，用于把 LEGO EV3 接入
ScratchAI / TurboWarp 的 VSLE-EV3 扩展，并通过本机 WeisileLink 与 EV3
通信。

当前状态说明：

- macOS 包：已有 unsigned Internal Test Release，可做内部测试。
- Windows 包：当前文件夹只包含安装脚本和构建脚本，Windows release zip 需要在
  Windows 主机或 GitHub Actions `windows-latest` 上生成。
- 外部课堂发布：仍需要签名、macOS notarization、Windows code signing，以及
  clean-machine 安装 smoke evidence。

不要把 pairing token、学生数据、API key 或原始诊断日志写入本向导包。

## 1. 准备硬件

准备：

1. LEGO MINDSTORMS EV3 主机一台。
2. 8GB 或 16GB microSD/microSDHC 卡一张。
3. 读卡器。
4. 老师电脑一台。
5. EV3 mini USB 线。
6. 已充电电池或稳定电源。
7. 如果走 WiFi Full VSLE，准备兼容 EV3 的 WiFi USB dongle。

课堂首选路径：

- 有 WiFi dongle：使用 WiFi Full VSLE。
- 没有 WiFi dongle：使用 `Bluetooth Full VSLE`。这仍然要求 EV3 运行 ev3dev 和
  EV3SC 的 `vsle_ev3_server.py`。
- `Official Firmware Bluetooth Compatibility` 只是有限兼容模式，不等同于 Full VSLE。

## 2. 刷写 ev3dev SD 卡

打开：

```text
install-wizard/files/01-sd-card/
```

macOS 老师使用：

```text
balenaEtcher-1.17.0.dmg
```

Windows 老师使用：

```text
balenaEtcher-Setup-1.17.0.exe
```

EV3 镜像使用：

```text
ev3dev-stretch-ev3-generic-2020-04-10.zip
```

步骤：

1. 插入 microSD 卡。
2. 打开 Balena Etcher。
3. 点击 `Flash from file`。
4. 选择 `ev3dev-stretch-ev3-generic-2020-04-10.zip`。
5. 选择外置 microSD 卡作为 target。
6. 再次确认 target 不是电脑内置磁盘。
7. 点击 `Flash`。
8. 等待写入和验证完成。
9. 安全弹出 SD 卡。

把 SD 卡插入 EV3，开机。首次启动可能需要几分钟，请等到 ev3dev / Brickman
界面出现。不要在 `Starting` 阶段随意断电。

## 3. 第一次登录 EV3

如果 WiFi 可用，在 EV3 的 Brickman 菜单中打开 `Wireless and Networks`，连接网络并记录 IP。

如果 WiFi 不可用，使用 USB：

1. 用 mini USB 线连接 EV3 和 Mac。
2. 确认 Mac 出现 `EV3+ev3dev` 网络服务。
3. 使用 Brickman 或 Bonjour 找到 EV3 的 IPv6 link-local 地址。
4. 登录：

```bash
ssh -6 robot@fe80::16:53ff:fe4f:4655%en10
```

默认账号：

```text
username: robot
password: maker
```

上面的 `%en10` 只是示例。每台 Mac 的接口名可能不同。

## 4. 安装 EV3 端 VSLE Server

打开：

```text
install-wizard/files/02-ev3-server/
```

需要复制到 EV3 的内容：

- `ev3-firmware/`
- `websockets-7.0.tar.gz`

在老师电脑上执行，替换成当前 EV3 SSH 地址：

```bash
cd /Users/yukii/Desktop/EV3SC

ssh -6 robot@fe80::16:53ff:fe4f:4655%en10
rm -rf ~/vsle-ev3-firmware
mkdir -p ~/vsle-ev3-firmware
exit

scp -6 -r \
  install-wizard/files/02-ev3-server/ev3-firmware/README.md \
  install-wizard/files/02-ev3-server/ev3-firmware/vsle_ev3_server.py \
  install-wizard/files/02-ev3-server/ev3-firmware/scripts \
  install-wizard/files/02-ev3-server/ev3-firmware/systemd \
  install-wizard/files/02-ev3-server/websockets-7.0.tar.gz \
  'robot@[fe80::16:53ff:fe4f:4655%en10]:~/vsle-ev3-firmware/'
```

在 EV3 上安装离线 `websockets` 依赖：

```bash
ssh -6 robot@fe80::16:53ff:fe4f:4655%en10
cd ~/vsle-ev3-firmware

SITE="$(python3 -c 'import site; print(site.USER_SITE)')"
mkdir -p "$SITE"
rm -rf /tmp/websockets-7.0
tar -xzf websockets-7.0.tar.gz -C /tmp
rm -rf "$SITE/websockets"
cp -r /tmp/websockets-7.0/src/websockets "$SITE/websockets"
python3 -c 'import websockets; print(websockets.__version__)'
```

预期输出：

```text
7.0
```

编译检查并安装服务：

```bash
python3 -m py_compile vsle_ev3_server.py
python3 - <<'PY'
import ev3dev2, websockets
print('ev3dev2=' + ev3dev2.__version__)
print('websockets=' + websockets.__version__)
PY

SKIP_PIP_INSTALL=1 ./scripts/install.sh
systemctl is-enabled vsle-ev3-server.service
systemctl is-active vsle-ev3-server.service
```

预期：

```text
enabled
active
```

## 5. 选择 EV3 连接方式

### 5.1 WiFi Full VSLE

在 EV3 上确认 IP：

```bash
hostname -I
```

在老师电脑启动 WeisileLink 开发检验路径：

```bash
cd /Users/yukii/Desktop/EV3SC
PYTHONPATH=weisile-link \
EV3_IP=<EV3_IP_OR_HOST> \
EV3_WS_PORT=8765 \
WEISILE_TRANSPORT=wifi \
.venv/bin/python -m weisile_link
```

确认本机 Scratch Link 兼容端口可访问：

```bash
nc -z -w 2 127.0.0.1 20111
```

### 5.2 Bluetooth Full VSLE

Bluetooth Full VSLE 是无 WiFi dongle 课堂的完整模块路径。EV3 必须运行 ev3dev，
不能使用官方 LEGO firmware。

在 EV3 上读取 Bluetooth 地址：

```bash
hciconfig -a | grep "BD Address"
```

启用 EV3 端 RFCOMM listener，替换地址：

```bash
cd ~/vsle-ev3-firmware
VSLE_EV3_ENABLE_BLUETOOTH=1 \
  VSLE_EV3_BT_ADDRESS=<EV3_BLUETOOTH_ADDRESS> \
  VSLE_EV3_BT_RFCOMM_CHANNEL=1 \
  SKIP_PIP_INSTALL=1 \
  ./scripts/install.sh
sudo systemctl restart vsle-ev3-server.service
systemctl is-active vsle-ev3-server.service
```

如果 EV3 Bluetooth 显示未启用：

```bash
for f in /sys/class/rfkill/rfkill*/soft; do
  [ -e "$f" ] && echo 0 | sudo tee "$f"
done
sudo hciconfig hci0 up
sudo hciconfig hci0 piscan
printf 'show\nquit\n' | bluetoothctl
```

在 Mac 上先配对 EV3，再启动本地 WeisileLink：

```bash
cd /Users/yukii/Desktop/EV3SC

PYTHONPATH=/Users/yukii/Desktop/EV3SC/weisile-link \
WEISILE_TRANSPORT=vsle-bluetooth \
EV3_BT=<EV3_BLUETOOTH_ADDRESS> \
WEISILE_VSLE_BT_ADAPTER=/Users/yukii/Desktop/EV3SC/desktop/build/macos/native/WeisileEV3BluetoothAdapter \
WEISILE_LINK_HOST=127.0.0.1 \
WEISILE_LINK_PORT=20111 \
TRAINER_WS_PORT=8766 \
WEISILE_ALLOWED_ORIGINS="http://101.42.92.6:18612,http://127.0.0.1:8611,http://localhost:8611" \
/Users/yukii/Desktop/EV3SC/.venv/bin/python -c "from weisile_link.cli import main; main()"
```

如果需要 pairing token，请在终端隐藏输入，不要写进聊天或文件：

```bash
printf 'Paste EV3 pairing token, then press Enter: '
IFS= read -rs WEISILE_PAIRING_TOKEN
printf '\n'
export WEISILE_PAIRING_TOKEN
```

## 9. 课堂安全检查

上课前：

1. EV3 电量充足。
2. 机器人放在地面或低测试垫上。
3. 轮子和机械结构周围没有手。
4. WeisileLink 只绑定 `127.0.0.1`，除非老师明确启用 LAN。
5. ScratchAI 已加载 Unsandboxed VSLE-EV3 扩展。
6. EV3 reporter 和 Boolean 积木读取缓存值，不在积木执行时发网络请求。
7. 紧急停止流程可见：
   - 先按 Scratch 红色停止按钮。
   - 再停止 WeisileLink。
   - 如仍有动作，关闭 EV3。

## 10. 常见问题

ScratchAI 连不上：

- 确认 WeisileLink 正在运行。
- 确认 `127.0.0.1:20111` 可访问。
- 确认浏览器页面来源在 `WEISILE_ALLOWED_ORIGINS` 中。

Bluetooth 已配对但没有传感器数据：

- 确认 EV3 运行 ev3dev，不是官方 firmware。
- 确认 `vsle-ev3-server.service` 是 `active`。
- 确认 EV3 端 `EV3_ENABLE_BLUETOOTH=1`。
- 确认 pairing token 只在本机安全输入，不写入日志。

macOS 打不开 WeisileLink：

- 这是 unsigned internal build 的预期系统提示。
- 仅内部测试可按测试机安全策略打开。
- 外部课堂需要 signed + notarized 发布包。

Windows 没有安装包：

- 当前仓库没有 Windows release zip。
- 需要在 Windows 主机运行 `windows/build-release-windows.ps1` 生成。
- 生成后还需要 clean-machine install smoke evidence。

## 11. 完成标准

内部 macOS 自测可接受的最低结果：

- `install-wizard/check_install_files.sh` 通过。
- EV3 成功启动 ev3dev。
- `vsle-ev3-server.service` 为 `active`。
- WeisileLink 监听 `127.0.0.1:20111` 和 `127.0.0.1:8766`。
- ScratchAI 加载 EV3 扩展并出现红色 EV3 分类。
- `Bluetooth Full VSLE` 或 WiFi Full VSLE 有真实 EV3 sensor update。

外部课堂发布还必须满足：

- macOS signed + notarized。
- Windows signed + timestamped。
- 安装包来自 release artifact。
- 重启/重新登录后自动启动。
- 诊断导出默认脱敏。
- uninstall 可验证。
- `scripts/run_desktop_install_smoke.py` 接受对应 evidence。
